# 伪基站发现系统（众包采集 + 多特征融合检测）

针对园区周边伪基站（IMSI Catcher / 非法小区）场景的防御性检测原型。
员工手机上的轻量采集端记录服务小区与邻区的网络层参数，服务端基于运营商
可信注册表做基线对照，融合 **14 类异常信号** 给出可解释的恶意概率与置信度，
并估计伪基站的**活动时间窗**和**地理区域（含不确定半径）**。

全部代码仅依赖 Python 3.9+ 标准库，无需安装第三方包。

## 快速开始

```bash
python run_demo.py                 # 默认 5 天仿真，输出到 output/
python run_demo.py --days 2 --seed 7 --out output/s2
python -m unittest discover -s fbs_detector/tests -v
```

产物：

| 文件 | 内容 |
|---|---|
| `output/.../report.html` | 自包含检测报告（指标、证据分解 SVG、园区定位图、时间窗） |
| `output/.../alerts.json` | 结构化告警（含每条证据的 LLR 贡献，可对接 SOC） |
| `output/.../ground_truth.json` | 仿真地面真值，**检测器不读取**，仅评估环节使用 |

默认仿真（seed=42）的检测结果：4 个伪基站全部命中、**零误报**、F1=1.0、
定位中位误差 ~100m、发现时延 2–4 分钟；在 seed ∈ {1,7,13,42,99,2026} 上结果一致。
另有「无伪基站纯净网络」基线测试（含计划内 COW），三个种子下均为零告警。

## 系统架构

```
手机采集端 (collector/app.py)                服务端 (server/)
┌───────────────────────────┐      HMAC 签名批次       ┌──────────────────────────────┐
│ 网络指纹变化检测 / 本地去重 │ ───────────────────────▶ │ 验签入库 → 候选发射源归并      │
│ 批量缓存 / 弱网重发         │   (TLS 1.3 生产传输)      │ → 14 类信号提取 → LLR 融合     │
└───────────────────────────┘                          │ → 漂移聚类 → 置信度分级/告警    │
        ▲ 仿真数据源 sim/device.py                      │ → 时间窗 + 加权质心定位         │
        │ （真机对应 TelephonyManager 回调）             └──────────────────────────────┘
┌───────┴──────────────────────────────────────────────────────────────┐
│ sim/：三园区合法网络（含计划内 COW 临时站）+ 4 个隐藏伪基站 + 72 台设备 │
└──────────────────────────────────────────────────────────────────────┘
```

## 仿真了什么

**合法网络**：3 个园区各有 LTE 双宏站、5G 宏站、GSM 老站、室内小站，
含邻区关系、阴影/快衰落、室内穿透损耗；另在 P-A 园区部署一个运营商已报备的
**计划内 COW 临时小站**（检测器必须压住对它的误报）。

**四类伪基站（检测器侧不可见其定义）**：

| 编号 | 手法 | 关键模仿/破绽 | 时长 |
|---|---|---|---|
| R1 | GSM 降级诱捕（A5-0 不加密） | 中途漂移 LAC/CI/PCI 三次 | ~2 天 |
| R2 | LTE 盗用真实宏站 ECI（同 PCI） | TAC 错误、EEA0/EIA0、假位置偏离 215m | ~1.6 天 |
| R3 | 隐蔽寄生（加密完全正常） | 仅 TAC 错位、PCI 复用、TA 粗糙、身份漂移 | ~2.2 天 |
| R4 | 车载 GSM 短停（A5-1） | 只出现 3 小时，考验时间窗定位 | 3 小时 |

设备侧仿真了 waypoint 随机游走、夜间静止、RAT 优先级重选迟滞、
伪基站影响半径内的强制重定向（非 100% 捕获）、飞行模式切换等真实噪声。

## 判定逻辑：为什么不能靠单一特征

真实网络自身存在大量切换、扩容、临时站；伪基站又会模仿合法参数。
因此每个信号只贡献一份**对数似然比（LLR）证据**，按「被良性事件解释的
难度」标定权重，融合后才出结论：

```
logit(P_恶意) = logit(0.001)                              # 稀有事件先验，防先入为主
              + Σ 信号权重 × √触发次数                     # 同类重复证据边际递减
              + min(2.2, 0.55·log2(独立设备数))            # 多设备佐证，封顶
P_恶意 = sigmoid(logit)
```

| 信号 | 含义 | 权重 | 为什么是这个量级 |
|---|---|---:|---|
| S02 | 盗用 ECI 但 PCI/TAC/位置对不上 | 2.30 | 合法网络几乎不可能出现，最强犯罪信号 |
| S05 | 空口无/弱加密（EEA0/A5-0，未知站 A5-1） | 2.00 | 现代网络已淘汰，计划站仍走正常加密 |
| S07 | LTE/5G 异常回落到未知 GSM | 1.70 | 运营商清退 2G 中，回落本身可疑 |
| S08 | 已知 ECI 观测位置远离注册坐标 | 1.60 | 仿冒站的地理破绽 |
| S03 | 广播 TAC 不属于本园区 | 1.50 | 跨 TAC 调整有工程记录可查 |
| S06 | 完整性保护关闭 EIA0/NIA0 | 1.40 | 常与 EEA0 伴随，略弱于 S05 |
| S14 | 同位置未知发射源频繁换身份 | 1.30 | 身份漂移是反追踪特征，但设备故障也可能 |
| S04 | 同频 PCI 上出现第二个 ECI | 1.20 | PCI 混淆在密集组网下偶发 |
| S01 | ECI 不在运营商注册表 | 1.10 | 新站入网有窗口期，不能单独定罪 |
| S12 | TA 与 RSRP 反演距离不自洽 | 1.10 | 廉价伪基站时序粗糙，但室内反射也会 |
| S10 | 邻区表与规划无交集 | 1.00 | 伪基站通常不维护真实邻区表 |
| S13 | 多设备 30 分钟内集中首次发现 | 0.90 | 突然出现 vs 长期存在 |
| S09 | 多点位异常强信号（过覆盖） | 0.80 | 高功率是伪基站物理特征，受地形影响 |
| S11 | 异常高重选率 | 0.70 | 网络拥塞/干扰也会触发，权重最低 |

**置信度分级**：≥0.90 确凿(critical) / ≥0.70 高(high) / ≥0.45 中(medium) /
≥0.25 低(low)；低于 0.25 不告警，进入观察名单持续跟踪。

## 防误报的三道闸

1. **注册表白名单一票压制**：计划内 COW/扩容/退服在运营商报备窗口内的
   变化直接压制，但保留审计记录（`suppressed` 列表）。
2. **稀有事件先验 + √n 累加**：单条弱信号无法把候选推过告警线，
   同类信号重复触发收益递减，防止规则刷分。
3. **多设备独立佐证**：单台手机基带异常是常见噪声；N 台互不相识的设备
   同时观察到同一现象才计入强证据，且佐证收益封顶。

## 时空定位

- **时间窗**：观测时间戳排序后按 30 分钟空隙切分，输出每个活动窗口的
  起止时间；R4 这类短时事件的窗口被准确定位到 3 小时量级。
- **位置**：以信号强度为权重的众包加权质心，不确定半径 =
  观测散布（中位距离×1.25）+ 120m 信号反演残差，最小 100m。
- **身份漂移合并**：对注册表外候选按园区做 DBSCAN（ε=300m）并按
  制式/频点细分，R1 的三个漂移身份会合并为同一事件，不会报成三起。

## 采集端与真机落地说明

- 采集字段对应 Android `TelephonyManager`/`PhoneStateListener` 可获得的
  网络层信息（ECI、PCI、TAC、频点、RSRP/RSRQ、加密能力、邻区），
  **不采集通话/短信内容与个人标识**；iOS 对底层小区信息限制较多，
  生产方案以 Android 工作机/企业 SDK 为主。
- 生产环境传输安全由 TLS 1.3 保证，应用层 HMAC 防批量篡改；
  每机一密、密钥走设备证明通道下发。
- 上报采用事件驱动（驻留/制式/加密变化即报）+ 40 分钟心跳，
  本地指纹去重，弱网缓存重发。

## 局限与后续方向

- 纯被动采集无法发现只监听不广播的「沉默伪基站」，需要结合空口扫描（SDR）。
- 室内 GPS 漂移会放大定位半径，可引入 PDR/蓝牙信标辅助。
- 权重目前为专家标定 + 仿真校验，积累真实标注数据后可改为
  保序回归/逻辑回归学习权重，LLR 框架本身不变。
- 未覆盖伪基站对测量报告的主动干扰（reject 信令风暴），需基站侧数据补充。
